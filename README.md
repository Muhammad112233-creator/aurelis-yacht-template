# Aurelis 62 — Cinematic Yacht Website Template

A premium, responsive React + Vite experience for a fictional performance yacht brand. It includes an opening transition, full-screen hero, editorial detail chapters, animated image gallery, specifications, day-to-night storytelling, menu overlay, custom sound ambience, inquiry CTA, and mobile layouts.

All product names, copy, identity, and AI-generated images in this demo are original concept material. No images or logos from the reference brand are included.

</div>

## Local setup

1. Install Node.js 20 or later.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Customize

- Text and section data: `src/main.jsx`
- Colors, typography, spacing, animation: `src/style.css`
- Images: `public/images/`
- Email link: search for `studio@example.com` in `src/main.jsx`
- Repository base path: automatic; the included workflow builds the correct GitHub Pages URL.

Keep replacement image filenames unchanged for the fastest edits, or change the corresponding entries in `src/main.jsx`. Recommended dimensions: landscape images at least 1920×1080; detail images at least 1400×1050.

### Updating later

Use **Add file → Upload files**, drag changed files, and commit. GitHub Actions republishes automatically.

## Production build

Run `npm run build`. The generated production files appear in `dist/`. Do not commit `dist`; the workflow creates it during deployment.
